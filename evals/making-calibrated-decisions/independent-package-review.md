# Independent package review

Reviewer: `skill15-package-review`

## Initial findings

1. **Blocker:** the runtime lacked exclusive output modes, so specialist-owned and source-only requests could be forced through a generic decision record and invented action branches.
2. **Important:** exact-once evidence categories overlapped because an observed artifact could make its asserted proposition appear observed rather than claimed.
3. **Important:** competition and platform-position work lacked an explicit route to `competing-and-positioning`.

## Remediation

- Added exclusive `route-away`, `source-calibration`, and `cross-domain-decision` modes with explicit stop conditions.
- Classified propositions rather than containers: an artifact's existence and text may be observed while its assertion remains claimed until independently established.
- Added the exact `competing-and-positioning` route.

## Verification

The same reviewer re-read only the three affected contracts before package freeze. All three findings passed re-review with no residual blocker. Trigger specificity, seven inherited invariants, reversible and irreversible gates, product-specific evidence latency, source calibration, writing boundaries, the exact 134-essay/14-theme provenance projection, structural validation, taxonomy synchronization, and package copyright hygiene passed. Evaluation responses and criteria were excluded from this review.
