# Competing and Positioning

## Route first

- If default-dead or time-to-zero binds, use `managing-runway-and-survival` first.
- Until one segment shows predeclared discriminating commitment, `learning-from-users` owns evidence. Return only `State/ownership: learning-first`; its primary owner; verified evidence; one hypothesis; retained alternatives/dependencies; dated gate; and handoffs to `learning-from-users`, `acquiring-and-growing-users`, `shipping-and-iterating-products`, then this skill. Stop.
- For platform creation, gate core product, not complement: core commitment activates positioning while complement evidence may remain unknown.
- `engineering-for-leverage` owns architecture; `shipping-and-iterating-products` rollout; `acquiring-and-growing-users` channels/liquidity; `designing-business-models` economics/boundaries.
- `building-and-evolving-organizations` owns people; `navigating-acquisitions-and-exits` transactions; `raising-and-governing-capital` financing/control; `governing-platforms-and-communities` policy/abuse; `communicating-clearly` settled publication.
- If another specialist is primary and no positioning issue remains, return only `State/ownership: route-non-trigger`; evidence; promise implication; primary owner; ordered exact-skill handoffs; positioning's limited role. Stop.

## Build the record

Begin `State/ownership: positioning-active`, `Primary owner: competing-and-positioning`, and ordered exact-skill `Handoffs:`. Record facts, bounded inferences, unknowns, and:

1. date, stage, product row, constraint, latency, reversibility;
2. user, job, outcome, commitment, and every material manual/status-quo, direct, indirect, platform-native, same-resource, integrated-core, and independent-complement alternative;
3. each alternative's predecessor problem, outcome, switching, signals, lead, velocity, distribution/control, incentives/constraints;
4. `mechanism -> capability -> user effect -> commitment effect -> copy barrier -> continuing refresh`;
5. a bounded portfolio. Every material test locally repeats operational person, baseline, exposure, metric, confounders, date, disconfirmation, preserved option, and observable pass/change/stop condition. Unsupported cutoffs locally include `proposed`, rationale, error tradeoff, and revision rule. Global prose cannot fill another test. Shared exposure counts only when each hypothesis, action, metric, and readout is independently adjudicable.

Use rival evidence only when it changes the user thesis, alternative map, switching constraint, capability gap, or response; otherwise stop surveillance. Compare causal choices, not feature parity. Moats require the complete observed chain and disproportionate duplication difficulty.

For incumbents, test distribution, velocity, legacy constraints, cannibalization, ability, and incentive; predeclare `ignore/copy/bundle/block/acquire/litigate/unknown`. Test end-to-end substitution before `integrate/reposition/rebuild/partner/pivot`.

Do not deepen platform dependence without policy, direct-user, portability, migration, and exit evidence; precommit `double-down/diversify/redesign/migrate/stop`. Separate applicable portability, direct-user, alternate-channel, restricted-API, substitution, and builder-loop tests.

Platform creation requires executed, verified rollback before readout. Priority: breach→stop; no value + validated core need→keep; other no loop/value→stop. Precommit exactly:

- `keep-integrated`: validated core need and no complement value; shipping rolls back, engineering retires interfaces, learning reconfirms.
- `expose-bounded-interfaces`: recurring value with an unknown prerequisite; shipping preserves revocability, engineering bounds, learning closes named gaps.
- `expand-ecosystem`: repeat builders, recurring value, attributable demand, credible governance/economics; learning closes gaps, then governance/economics, engineering/release, finally growth owns adoption/liquidity.
- `stop-platform-bet`: absent loop/value or breached limit; shipping rolls back, engineering retires, learning checks remaining core need.

Each outcome locally separates positioning's decision/action from its operational person and ordered exact-skill handoffs/actions; no fifth/global substitute. Rollback outcomes locally prove the core product and direct customer/user relationship remain unharmed. Never invent data.
