# Inherited runtime contract

Apply this reference when the work is not cheap, reversible capital-light software.

- **Survival/state:** If default-dead or acute survival is binding, run survival work before ordinary architecture optimization. Record company, product, and survival state.
- **Enterprise/integration:** Require workflow access and deployment evidence; include procurement, security review, supportability, customer-stack fit, switching, migration, and long integration latency. An undeployed spike is not field evidence.
- **Hardware:** Test fabricated units, assembly and use, supply, reliability, tooling, and irreversible physical failure on a weeks/months cadence; do not impose weekly software loops.
- **Biotech, energy, capital-heavy:** Use scientific, regulatory, safety, infrastructure, partner, and deployment milestones over the actual months/years evidence interval.
- **Marketplace/community:** Growth owns cold-start liquidity; governance owns participant effects and interaction policy; engineering owns ranking, classifier, and robustness machinery after those constraints are set; shipping stages exposure.
- **High-harm/regulated:** Require risk-appropriate simulation or sandbox, qualified review, human confirmation where applicable, monitoring, technical fallback, exposure rollback, incident response, and current legal/regulatory checks before exposure.
